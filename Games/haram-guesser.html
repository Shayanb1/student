🕌 Haram or Not?

A two-player word guessing game. One player secretly picks a haram word, the other asks yes/no questions to figure it out. First to guess correctly wins.

Terminal / CLI Game  ·  Node.js  ·  No API key required
  1. 1. Clone the repo if you haven't already
  2. 2. Open a terminal in the project folder
  3. 3. Run:

cd Games/haram-guesser
npm install
npm start

Player vs Computer fully playable  ·  Player vs Player coming soon
